通过贴近实际的场景、完整应用和共享待办事项，在软件开发生命周期中探索 GitHub Copilot。你将以迭代方式规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌游提供众筹服务，主题围绕开发者文化。团队的待办事项已作为 GitHub 议题创建，随时可以开始处理。其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择最适合自己构建项目的环境。每个研讨会都有独立的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 以及实用斜杠命令。

### [GitHub Copilot app][app]

运行并行代理会话、切换会话模式、协作处理画布，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步代理，指导其工作、监控进展，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。通过 Copilot Chat 代理模式、MCP 服务器和自定义代理开展工作，无需离开编辑器。
